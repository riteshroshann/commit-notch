Developer docs

Commit Notch is a small Electron app: one transparent window, plain JavaScript, no framework and no build step for the UI. Everything below is enough to change any part of it. Edit this page on GitHub

Run it locally

You need Bun and, for the task shortcuts, just. Node isn't required: packaging runs on the Node that ships inside Electron.

git clone https://github.com/riteshroshann/commit-notch
cd commit-notch
bun install
just dev

If VS Code launched your terminal, it sets ELECTRON_RUN_AS_NODE, which makes Electron behave like plain Node. just dev clears it for you. Running electron.exe . by hand needs the same.

Architecture

A frameless, transparent, always-on-top window 1240 px wide sits at the top centre of the primary display. It ignores the mouse everywhere except over an island: the page reports hover changes over IPC, and the main process flips setIgnoreMouseEvents. That's how clicks fall through to whatever is underneath.

On launch, the main process sends the cached data from the last run straight away, so the islands paint instantly. Then it fetches fresh data. Contributions refresh every 15 minutes and the clock resyncs every 10. Losing focus closes any open panel. A second launch opens the panel in the running instance instead of starting another one.

GitHub data

One GraphQL call to viewer returns everything: contributionsCollection (calendar, totals and the top four repos by commits) and the four most recently pushed repositories. Contributions to private repos are included for your own account. Your profile setting decides whether they also show on github.com.

People sign in three ways, all from the setup window in src/setup/. Continue with GitHub runs the OAuth device flow (src/auth.js): the app asks GitHub for a short code, opens the browser, and polls until the person approves. If the GitHub CLI is signed in, its token is picked up with no setup at all. A classic token with repo and read:user scopes can be pasted as a fallback.

Every token is checked against GitHub before it replaces the current one, then encrypted with Electron's safeStorage (Windows DPAPI). The cache is tagged with a hash of the token, so data from one account never paints for another, and an internal sign-in epoch drops any fetch that started before a sign in or sign out. A 401 forgets the token and returns to the signed-out state, which shows no name and no data.

Device flow needs an OAuth App with Enable Device Flow ticked. Put its client ID in package.json as githubClientId, or set COMMIT_NOTCH_CLIENT_ID while developing. Client IDs are public; device flow uses no client secret. Without one, setup offers the CLI and token routes only.

Atomic clock

ntp.js sends four SNTP requests to time.cloudflare.com over UDP 123, keeps the one with the shortest round trip, and computes the offset as ((t1 − t0) + (t2 − t3)) / 2. The page adds that offset to Date.now() and schedules each tick on the true second boundary. If the server can't be reached, the dot goes grey and the clock falls back to the PC's own time.

Motion and sound

Whether something is visible is always decided by a CSS class with a transition, never by an animation that holds its end state. Interrupt it however you like and it settles on the current state. Script animates only geometry: an island's width and height when it opens, starting from wherever it is right now.

The springs are real. Motion.spring(stiffness, damping) simulates a damped spring and samples it into a CSS linear() easing, exposed as --spring for the stylesheet. Opening uses a bouncier spring than closing.

Every sound is generated live with Web Audio: sine tones with pitch glides, plus a short band-passed noise burst for the tap. There are no audio files. Edit sound.js to retune them, or turn them off from the menu.

Settings and storage

Everything lives in %APPDATA%\Commit Notch\: settings.json (sounds on or off, and the clock's cities), token.bin (encrypted) and cache.json (the last good data). To change the cities, edit the file and restart:

{
  "sound": true,
  "cities": [["San Francisco", "America/Los_Angeles"], ["London", "Europe/London"]]
}

Install and uninstall

The installer is a per-user NSIS one-click build: no admin rights, installed to %LOCALAPPDATA%\Programs\commit-notch, with a Start menu shortcut and an entry in Settings → Apps and Control Panel. Uninstalling runs build/installer.nsh, which quits the app and removes its start-at-login entry, and deleteAppDataOnUninstall removes the encrypted sign in, cache and settings.

Commit-Notch-win.exe /S
"%LOCALAPPDATA%\Programs\commit-notch\Uninstall Commit Notch.exe" /S

Testing

just check runs the unit tests for the streak and calendar logic. Setup has its own render check: electron . --setup-shot=out/setup saves every pane as a PNG. just e2e launches the real app and puts it through 14 scenarios: opening, bursts of fast and held arrow keys, wheel bursts, closing and reopening mid-transition, switching islands, rapid clicks and focus loss. After each one it checks the DOM state and measures the pixels inside the open island, so a blank panel fails the run. Screenshots and a report land in the folder you pass.

electron . --e2e=out/e2e
electron . --shot=out/panel.png --open=gh --page=2

--shot opens an island (and optionally a page), saves a screenshot and quits. It's handy for checking visual changes.

Releasing

Bump version in package.json, run just check and just e2e, then just dist. Upload both files to a GitHub release:

gh release create v1.2.0 dist/Commit-Notch-win.exe dist/Commit-Notch-win.zip --title "Commit Notch 1.2.0" --notes "..."

The file names don't include the version, so the download buttons on this site, which point at releases/latest/download/, always give people the newest build.

Contributing

Issues and pull requests are welcome. Keep the bar: just check and just e2e pass, no new runtime dependencies without a good reason, no sound or font files, and it should still feel like hardware. Springy, quiet, never in the way.
